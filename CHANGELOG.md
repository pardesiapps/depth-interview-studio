# Changelog

## 1.0.1

- Every dark palette uses the same neutral charcoal page/card surfaces while preserving its accent color.

- Copy-success feedback swaps the outline icon for a theme-colored animated checkmark and a brief “Copied!” tooltip.
- Icons reset after two seconds; clipboard failures retain the original icon and fallback.
- Reduced-motion preference disables transitions and checkmark drawing.

## 1.0.0

- Personal-data-free three-page Interview Studio starter.
- Agent-led onboarding: profile/experience, then personal/employer/résumé, then optional Gmail application tracking.
- Five palettes, light/dark appearance, three visual styles, typography and UX reference.
- Transparent outlined theme-colored copy controls.
- Configurable profile and 50-question sample deck; persistent owner-authorized R2 application backend.
- Local loopback development preview, validation scripts and update guidance.
- Gmail automation requires an independently verified connection; no copied identity, credentials, application data or working-sync claim.
